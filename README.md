# Anup Bhagat – Portfolio

Personal portfolio site: plain HTML and CSS with no build step, hosted on GitHub Pages.

## Deploy
1. Create a public repo named `<your-github-username>.github.io`.
2. Upload `index.html`, `README.md` and the `assets/` folder (Add file → Upload files → Commit).
3. Go to Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
4. After about a minute the site is live at `https://<your-github-username>.github.io`.

To update the CV, replace `assets/Anup_Bhagat_CV.pdf` and keep the same file name.
